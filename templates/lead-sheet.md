# 客户表建议字段

新建一张表格时，建议至少包含以下列。来源和「待核实」标记必须保留，方便业务员回查。

| 列名 | 说明 |
| --- | --- |
| 品牌名 | 对外品牌，不是工厂内部编号 |
| 国家/市场 | 品牌主要市场或总部所在地 |
| 官网 | 当天打不开则不要收录 |
| 语言 | 开发信使用的语言 |
| 客户类型 | 优先：独立品牌；可补充进口商、零售商等 |
| 公开邮箱 | 多个邮箱分行或分号隔开；不要猜测 |
| 电话 | 公开电话，注明来源 |
| WhatsApp | 公开号码，注明来源 |
| 决策人姓名 | 与公司对不上则留空 |
| 决策人职务 | 创始人/老板/CEO 优先，其次采购或产品负责人 |
| 决策人 LinkedIn | 公开搜索得到的主页，不登录、不加好友 |
| 公司 LinkedIn |  |
| 社媒主页 | Instagram、TikTok、Facebook 等 |
| 来源 | 这条信息是从哪里查到的 |
| 客户洞察 | 产品、定位、近期动态、供应链线索 |
| 适配产品/系列 | 对照现行产品手册，不要编造 |
| 优先级 | 例如 A/B/C，并写一句理由 |
| CRM 状态 | 已入 CRM / 无邮箱，未入 CRM |
| 草稿状态 | 已存草稿（语言）/ 未写 / 使用者已发送 |
| 发送与退信 | 送达、退信、回复；无更新可留空 |
| 备注 | 待核实事项或其他提醒 |
